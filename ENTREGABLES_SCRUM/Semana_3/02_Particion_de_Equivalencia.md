# Semana 3 - Partición de equivalencia

## Regla

El progreso de una actividad debe estar entre 0 y 100.

| Partición | Validez | Representante | Caso |
|---|---|---:|---|
| Menor que 0 | Inválida | -1 | CP-MFC-007 |
| 0 a 100 | Válida | 50 | CP-MFC-004/005 |
| Mayor que 100 | Inválida | 101 | CP-MFC-006 |

Las particiones son no solapadas y cubren el dominio relevante de la regla.
